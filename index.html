01 · Overview

Claude Desktop이란?

웹 브라우저를 넘어, macOS·Windows에 직접 설치되는 Claude의 데스크톱 애플리케이션입니다.

네이티브 앱

브라우저 탭이 아닌 독립 실행형 앱으로 상시 대기

로컬 연동

내 파일, 폴더, 앱과 직접 상호작용 가능

확장된 능력

MCP를 통해 외부 도구·서비스까지 제어

03 · MCP

Model Context Protocol

Claude가 외부 시스템과 안전하게 연결되도록 만드는 개방형 표준입니다.

Claude Desktop

MCP 서버

Google Drive, Slack, DB 등

필요한 도구를 표준화된 방식으로 연결해, 매번 새로 통합을 만들 필요가 없습니다.

05 · Why

왜 Claude Desktop인가

컨텍스트 전환 없이 필요한 작업을 한 자리에서 처리

로컬 데이터 접근 권한을 세밀하게 제어하여 필요한 폴더만 안전하게 공유

확장 가능한 생태계, MCP로 원하는 도구를 자유롭게 연결

일관된 사용 경험, 웹과 동일한 Claude를 데스크톱에서도
